## About

Freelance developer building web scraping, automation, and internal tools for small businesses.

Most of my work replaces something a person is doing by hand every morning: copying product data between two systems, checking a page for changes, retyping orders that arrived by messenger.

35+ projects delivered since 2023. Available for remote work.
